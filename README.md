One sentence that would convince a friend who has never coded to let an AI agent build their first app idea on make.fun, written for the [A Day of One-Line Pitches](https://make.fun/bounty/u-ronigrv-a-day-of-one-line-pitches-12cd9bb3) bounty on [make.fun](https://make.fun).

```
You've had that app idea for years, so just describe it to an AI agent on make.fun and let it build the whole thing while you watch — no code, no cost, and tonight you can show your friends what you made.
```

`main.py` (standard library only) writes the pitch to `/output/entry.txt`.
